# دليل التنين الذكي

هذا المستودع **عام (Public)**، ويحتوي على أدلة الاستخدام العامة فقط.

- الصفحة الرئيسية: دليل الخدمات والبحث.
- صفحات الخدمات: شرح الخطوات المتاحة للجمهور.
- لا تُنشر هنا تعليمات الإدارة المحمية أو معلومات البنية الداخلية أو بيانات الوصول.

تُدار أدلة الموظفين والصلاحيات بصورة مستقلة داخل بوابة الشركة المحمية. ولا يُعد نشر دليل عام تصريحًا بعرض محتوى داخلي.
